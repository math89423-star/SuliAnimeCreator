# 客户演示流程 · SuliAnimeCreator（短剧创作 + 批量投流）

> 演示环境：Suli 前端 http://127.0.0.1:5173 ｜ 后端 :5001（容器 `sulianimecreator-*`）
> L-Port 前端 http://127.0.0.1:8080（执行侧，草案包解析后在那里跑图/跑视频）
> 总时长建议 32 分钟：开场 2′ → 短剧线 15′ → 投流线 13′ → 收尾 2′
> 一句话定位（开场必说）：**Suli 只负责起草方案与定方向，不直连生成；成品执行在 L-Port。**

---

## 线 A · 短剧创作（15′，用现成集 EP-81695F，全程无等待）

演示集：**EP-81695F**（大纲已出、草案 3 镜 3s+4s+3s=10s、首帧已挂、前后端已实测走通）。

| 步骤 | 页面/操作 | 讲什么 | 预期结果 |
|---|---|---|---|
| A1 角色 | `/character` 角色库 | 成年角色锚点 + 槽位图（服装/脸/场景），锁面不编 | 角色卡 + 槽位图展示 |
| A2 大纲 | `/director` → 选 EP-81695F → **大纲** tab（默认） | agent 按首帧图出方案大纲：方向一句话/镜表/时长；分级按内容自动判（本集 nsfw→explicit 档） | 大纲 md + 大纲图正常显示 |
| A3 草案 | 同页 **剧本** tab → 转草案已有 3 镜 | 每镜：中文 duty（看板）+ 英文 duty_en（拼提示词）+ 运镜 10 选一 + 首帧挂 M002；多图参考走 Multi-Reference（v4/Tsubaki Video），v3.x/v2.7 只认首帧 | 3 镜列表，首镜带图 |
| A4 导出草案包 | 草案 tab → **导出草案包** | ZIP=去程交付包：manifest.json(sha256) + shots.json(含每镜 ref_mode) + beats.json + prompts/ + slot_images/ + episode_refs/ + 大纲图 | 下载 `草案包-EP-81695F.zip`（约 8MB，17 个文件） |
| A5 交接 L-Port | 浏览器切 L-Port :8080（或贴已验证结果） | `POST /api/pipeline/parse-draft-bundle` 只收 .zip；已实测本集解析 `missing:0, shots=3, beats=6` | 解析成功页 / `missing_files:0` |
| A6（可选）视频参考 | 拉片室页 `/video`：（上传 / 直链 / **H站链接自动下载**）→ 时间轴圈选片段 → 抽帧 → Agent 拉片；「素材源」分页管理已拉素材（全选 / 批量删除 / 手动上传） | 时间轴双手柄拖 start/end（拖动实时预览画面）；只抽所选区间（缺省全片）、无切点自动转均匀采样；帧墙逐张可放大；Agent 看图反推运镜/节奏/钩子出拉片报告（只借手法不抄画面）；素材源列 uploads 视频（H站下载/上传自动入库，同名复用），载入即本地文件模式（抽帧零拷贝） | 关键帧图逐张显示 + 拉片报告 |

**A 步兜底**：A4 如下载慢，用 `/tmp/draft_bundle.zip`（已备好 8MB 实包）；A5 用已验证截图（`missing:0`）；全程不现场跑 agent（180s 不可控）。

## 线 B · 批量投流 → 出片（13′，两栈接力；实测 ①9.7s ②秒级 ④52.8s/3条）

> 一句话：**Suli 出「投流包」（定方向），L-Port 收包出成片（执行），数据回流 Suli 调下一批。**

### B1 定方向（Suli `/traffic`，2′）

| 步骤 | 操作 | 讲什么 | 预期结果 |
|---|---|---|---|
| B1-a | 任务行默认「引导点击红包广告 / 数量 15」→ **演示改 3** | 一条任务=一个测试方向，数量就是这批要测几条 | 任务卡就绪 |
| B1-b | 填**挂载位三件套**（任务级，全部变体继承）：搜索词=星灯短剧 / 小程序名=星灯短剧 / 贴片文案=点击领红包 看第七盏星灯 | 搜索词=观众搜什么；小程序名=落地页；贴片文案=烧进画面的挂载行 | 三框有值 |
| B1-c | 点 **运行** | skill（`skills/traffic/traffic-batch/SKILL.md`）驱动 LLM 出 钩子/假设/标题/CTA，钩子在 5 类里轮换、相邻不重复 | ~10s 出 3 条（T1-V01/V02/V03） |
| B1-d | 指 `checks` | 全绿才可交付：`mount_ok`/`deduped`/`naming_ok`/`testable`/`executable`，`engine=llm`（失败会标 `template`） | checks 打勾 |
| B1-e | 点 **导出ZIP**，打开包里三件 | `materials.csv`（每行带 搜索词/小程序名/贴片文案 三列＝交给剪辑的物料表）；`splice.txt`（`T1-V01 Hook4s[冲突直给] + Body[bbb action] + CTA3s[快点红包领钱!] 挂载[…] -> 15`）；`package.json`（机器包，下一步的输入） | 三列有值、splice 行尾带挂载标记 |

### B2 交给执行侧（L-Port → 投流素材，2′）

| 步骤 | 操作 | 讲什么 | 预期结果 |
|---|---|---|---|
| B2-a | **二选一**：① 省事版＝在 Suli 投流页点 **直投 L-Port**（勾「投完直接出片」就连出片一起触发）；② 演示版＝右上角 **上传草案包** 选刚导出的 `package.json` | 收件箱都是 `投流素材库/packages/`：① 走共享挂载直写（不依赖网络），② 是人工搬运那条老路 | ① 提示「已直投 L-Port（3 条）」或「已投递并开始出片（job …）」；② 提示「已上传：PKG-…（3条）」 |
| B2-b | 下拉选包 → 点 **运行** | 收包执行：按每条 variant 的**钩子前缀**在库内轮询同钩子源素材（没有则回退全库），逐帧烧字 | 约 55s 出 3 条；提示「已出 3 条成片（已进「产物」页签）」 |
| B2-c | 切 **产物** 页签 | 成片独立一页：视频资源 42 / 广告素材 47 / **产物 N**——素材与产物已分家，成片不会再被当源素材二次拼装 | 新成片按时间倒序在最前 |
| B2-d | 点开一条播放，逐层指给观众 | 四层：顶部**钩子花字**（58px 白、自动 2 行）+ 右下**红包角标**（红信封+金币¥+「红包/立即领取」，0.4s 弹出＋每 1.2s 呼吸）+ 底部**黄色 CTA** + **挂载小字**；横屏素材走「背景铺满+高斯模糊、前景居中」转 9:16；**素材比计划短会自动循环补帧**，每条都吃满 15s | 720x1280 / H.264 / 15.0s / 无音轨 / faststart |
| B2-d2 | 讲高光窗口（A 版，规则） | 素材够长就不从第 0 秒开始：**≥16.9s 跳片头 1.2s**（开头多是空镜/静帧）、**≥20s 取中段**（跳前 25%，例 31.7s 的素材 → 窗口 `[7.9s→22.9s]`）；素材不够长则整段用、循环补帧。窗口写进 `materials.csv`（`start_s/end_s` 两列）与 `splice.txt`（`窗口[a→b]`） | 抽帧可见：成片首帧 = 源素材第 7.9s 的画面，不再是片头 |
| B2-e | 勾 2-3 条 → **批量下载 ZIP** | 成片＋同名封面一起打包（封面取 t=1.5s 帧），拿到直接建投放计划 | 下载 `投流成片_<日期>_N条.zip` |

### B3 回流闭环（1′）

| 步骤 | 操作 | 讲什么 | 预期结果 |
|---|---|---|---|
| B3-a | 产物弹窗底部填 **CTR / 3s完播 / CVR** → **提交回流** | 文件名即测试方向：从 `PKG…_T1-V02_H002_720x1280.mp4` 解析出包号+变体，写回 Suli 投流复盘 | 提示「已回写 T1-V02」；再点「读已填」能读回 |
| B3-b | 看赢家：浏览器开 `http://127.0.0.1:5001/api/v1/traffic/report/<包号>` | 复盘按 ctr/3s完播 排序给 `winner`，下一批按数据给赢的 hook 加权 | winner 指向刚回填的变体（复盘 UI 暂缺，走 JSON） |

**B 步兜底**
- Suli 生成若 LLM 超时 → 后端自动模板回退，`checks.engine=template`，流程照走。
- L-Port 出片太慢/卡住 → 直接展示产物区**现成 5 条**（`PKG-TRAFFIC-EP-81695F-1015/1016`），说「这一步的产物已预先跑好」。
- 上传包失败 → 兜底命令：`cp package.json /home/administrator/L-Port-Comfy/app/backend/data/libraries/投流素材库/packages/`。
- 想更快：B2-b 前把包换成只含 1-2 条的包（`limit=1` 约 18s）。
- L-Port 前端起不来先看端口：`cmd.bash` 带 `FRONTEND_PORT=8080`；直接 compose 起会去抢宿主 80 端口。
