# Creative Divergence（通用发散 canonical）

> 归属：通用发散（画面/镜头/故事/服装方向）归本文件；角色身份层发散菜单归 `character-design`（本文件发散阶段不锁身份细节）；机位视角类发散与 `composition-camera` 联动只借机位词，不重定机位。

## 定位

- 输入：一个 idea（可模糊）或一个待发散的节点（角色 / 镜头 / 画面 / 服装 / 场景）。
- 输出：3-5 个**立意见明显不同**的方向（不是换词），每方向 = 一句话立意 + 视觉钩子 + 风险预判；收敛给 Top1 + 备选。
- 与 `character-design` 的分工：角色身份层的发散菜单（性格/属性组合）走 character-design；本 skill 管通用发散（画面 / 镜头 / 故事 / 服装方向），以及任何需要「多方向对照」的时刻。

## 发散原则（顺序不要乱）

1. **先量后质**：先保证方向数量（3-5），发散阶段不自我否决。
2. **异质优先**：方向之间必须换「立意」不是换形容词。检验法：两个方向能否用同一句话概括？能 = 没发散开。
3. 每方向一句立意 + 一个**视觉钩子**（一眼能认出的画面特征）。
4. 带**可生成性预判**：标注风险（多人手部 / 复杂文字 / 超多主体），复杂结构先降级。
5. **收敛不丢料**：被否方向里可回收的元素，写进 Top1 的「可选加戏」位。

## 方法菜单（跨用 ≥3 类，别只在一个维度里换词）

1. **属性组合**：主体 × 时代（古典/现代/近未来/幻想）× 气质 × 标志物。
2. **时空平移**：同一情绪换场景（古代/近未来/梦境/废墟）。
3. **反差设计**：气质 × 一件违和元素（冷淡 × 甜物；英气 × 蕾丝）。
4. **隐喻转译**：把抽象情绪翻译成可穿戴/可看见的符号（孤独 → 单侧耳饰、缺一半的对称）。
5. **二创融合**：借 1 件元素不借脸（撞车即废）。
6. **母题变体**：同角色/同主题的场合版本（校服版/私服版/礼服版/战损版）。
7. **视角反转**：微观/俯瞰/第一人称/旁观者位（与 `composition-camera` 机位区联动）。
8. **限制游戏**：给自己上限制（只用一个光源 / 只用一个颜色 / 只拍膝盖以下 / 全程背对），限制逼出创意。

## 输出格式

```markdown
## 方向N：<一句话立意>
**立意**：…
**视觉钩子**：…
**风险**：…
```

结尾：Top1 推荐 + 一句理由，并问 `继续发散 / 细化某条 / 换方向？`

## 实战样例（fx_A01 镜头发散）

- 方向A 压迫对峙：`from above ~30° + dutch 15°`——机位即威胁者。
- 方向B 平权交锋：`eye-level` + 正面直视 + 中心构图——谁都不压谁。
- 方向C 冷眼旁观：`3/4 back view` + 视线留白——观众站在她身后。
- 方向D 权力反转：贴地 + `from below`——她俯视威胁者。风险：JK 题材易变味。
- 收敛：选 A（「被堵但顶回去」的情绪只有俯角立得住），B 备选。

## 反模式（别做）

- 五条方向全是同一气质换场景 = 没发散。
- 方向之间自相矛盾却不自知（同时写沉默对峙和热闹街头）。
- 在发散阶段就锁死身份细节（那是 character-design 的收敛阶段）。
- 只给 1-2 个方向就急着收敛。
