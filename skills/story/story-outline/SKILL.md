# Story Outline（长篇大纲与分集细纲，规划层唯一入口）

> 出处（历史实战，不自造）：`SuliComfyUIAgent/project/outline_13.md`（13谎/四波/章钩）与 `CH01细纲.md`（幕/人物/四拍/分场/视觉三件套/原文存档/台词锁）。short-drama-write 只接细纲写剧本，不做大纲。

## 1. 长篇大纲（先锁世界，再排波次，最后落章）

1. **铁律**：1-3 条世界铁律（如单域雾谷/雾封闭塞、信使有求必应但不合心意），全剧任何章不得违。
2. **波次**：全剧分 3-5 波（如小地方起家→权贵获利→搅动王城→终末），每波写清本站（积攒什么、被谁注意）。
3. **章钩**：每章 = 标题 + 核心谎言（一句）+ 谁愿意（动机）+ 不合心意（代价）+ 域状态变化（一格）+ 钩（下章入口）。

## 2. 分集细纲（每集七件，缺一不开写）

1. **幕 title**：1-3 幕，每幕一句话题。
2. **人物**：出场人物的目标与筹码（只写本集 relevant 的）。
3. **四拍**：目标 → 阻碍 → 转折 → 钩子（转折必须有可追溯的事实/筹码/行动，不靠对手停反应）。
4. **分场**：按时长切（如竖屏 1-5 分钟 F1-F4），每场写清时长与内容。
5. **视觉件**：本集视觉母题三件套（如水/雾/梦），只拍反应不拍本体类纪律一并写。
6. **原文存档**：用户原话一字不改存档，后续评审对账用它不用转述。
7. **台词锁**：关键台词原文锁定（如收愿句），分镜对白照抄不改一字。

## 3. 门禁

- 大纲无铁律/无波次/章缺钩 → 打回。
- 细纲缺四拍转折依据/缺原文存档/台词未锁 → 不许进 short-drama-write。
