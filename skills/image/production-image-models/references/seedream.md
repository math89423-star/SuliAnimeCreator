# Seedream（火山方舟 doubao-seedream）出稿手册

> 来源：官方《Seedream 4.0-4.5 提示词指南》`volcengine.com/docs/82379/1829186` + 模型能力表 `.../1824718`。
> 一句话：**自然语言 + 明确用途**；支持文生图 / 图生图 / 多参考图 / 组图四大类任务。

## 1 通用规则（官方原文要点）

1. **用自然语言清晰描述画面**：简洁连贯地写 **主体 + 行为 + 环境**；对美学有要求就用自然语言或短语补 **风格、色彩、光影、构图**。
   - ✅ `一个穿着华丽服装的女孩，撑着遮阳伞走在林荫道上，莫奈油画风格。`
   - ❌ `一个女孩，撑伞，林荫街道，油画般的细腻笔触。`（碎片堆叠，不连贯）
2. **明确应用场景和用途**：有明确场景时，在提示词里写明**图像用途与类型**。
   - ✅ `设计一个游戏公司的 logo，主体是一只用游戏手柄打游戏的狗，logo 上写有公司名 "PITBULL"。`
   - ❌ `一张抽象图片，狗拿着游戏手柄，狗狗上写 PITBULL。`
3. **提升风格渲染**：有明确风格需求时，用**精准风格词**或**提供参考图像**。

## 2 高密度内容与知识图（Seedream 强项）

- 能把知识与推理结果转成高密度图像（公式、图表、教学插图）。
- 写的时候**用专业术语**保证知识点准确，并写清**可视化形式 / 版式 / 风格**：
  ```text
  在黑板上画出下列二元一次方程组及其相应的解法步骤：5x + 2y = 26；2x - y = 5。
  绘制一张信息图，展示通货膨胀的成因，每条成因独立呈现，并配有简洁图标。
  ```
- 多物件场景可以**逐个点名 + 逐个定位置**（官方示例里连书页上的维恩图三色、便签上的思维导图层数都点到）：
  ```text
  马克杯，杯上写着"Developer"，杯口冒出热气；一本摊开的书，页面是维恩图，展示三个圆的嵌套关系，三个圆分别为灰色、蓝色和浅绿色；……
  阳光从右侧照射，在桌上形成光影。
  ```

## 3 图像编辑（增 / 删 / 替 / 改）

用**简洁明确**的文字指示"编辑哪个对象 + 变成什么"：

| 操作 | 官方示例写法 |
|---|---|
| 增加 | `给图中女生增加相同款式的银色耳线和项链。` |
| 删除 | `去掉女生的帽子。` |
| 替换 | `把最大的面包人换成牛角包形象，保持动作和表情不变。` |
| 修改 | `让图中三个机器人变成透明水晶材质，颜色从左到右分别变成红黄绿。并让绿色的机器人跑起来，黄色的走路，红色的站立。` |

- **内容复杂、文字说不准编辑对象时**：用**箭头 / 线框 / 涂鸦**在图上标明区域，提示词里引用该区域：
  ```text
  将房间内红色涂抹位置放入电视，蓝色涂抹位置放入沙发，不改变其他布局，确保放入物体和整张图的原木风格一致。
  放大图中的标题至红框大小，并改成和萨克斯图案一样的颜色和字体风格。
  ```

## 4 参考图生图（两个部分必写）

有明确要保的特征（角色形象 / 视觉风格 / 产品设计）时上传参考图，提示词写两件事：

1. **指明参考对象**：要提取并保留的元素（`参考图中的人物形象` / `参考图中产品材质`）。
2. **描述生成画面**：要生成的画面内容与场景细节。

官方示例（照抄结构）：

```text
参考图中的人物形象，做一个动漫人物手办，放在桌上，后面放置一个印有角色图像的生日礼物包装盒，盒子下面有一本书，
在包装盒前面，添加一个圆形塑料底座，角色手办站在上面，将场景设置在室内，尽可能真实；
生成尺寸和现在图一样；手办在图片的左边；整个图片的风格和原始图一样，大片摄影感。
```

```text
参考图标的线性简约风格，设计9个不同场景下的应用 icon，包括：音乐、天气、日历、相机、聊天、地图、闹钟、购物车、笔记本，保持一致的配色。
```

```text
生成四件不同材质和颜色的上衣，衣服款式与图中女生身上的衣服一致，只要衣服，不要模特。
```

## 5 草图 → 高保真

平面图 / 线稿 / 手绘原型渲成成品图时三条：

1. 给**清晰的原始图**；图里有文字说明 → 提示词注明 **"遵循图中文字内容进行生成"**。
2. 明确主体与要求（`高保真 UI 界面` / `现代简约风格客厅实景图`）。
3. **点明必须与参考图一致的关键项**（`家具位置与参考图一致` / `按照原型图的布局`）。

```text
根据这张平面图，生成"现代简约风精装客厅 + 开放式餐厅"的实景图（房间布局、家具位置完全匹配例图）。
地中海风格配色，空间结构和方向始终与例图一致。……（不需要体现文字和手绘边缘）
```

```text
这是一个 Web 端房屋租赁软件的详情页手绘图，请根据图中文字示意，将其渲染成高保真的 UI 界面，
并在画廊区域增加一些示例图片，在房屋信息和预定信息区域增加一些示例的文字信息。
```

## 6 多图输入（替换 / 组合 / 迁移）

同时喂多张图时，**在提示词里逐个指明每张图的角色与操作**：

```text
将图一的主体替换为图二的主体。          // 替换
让图一人物穿上图二的服装。              // 组合
参考图二的风格，对图一进行风格转换。      // 迁移
```

## 7 多图输出（组图 / 分镜 / 成套设计）

- 支持生成**角色连贯、风格统一**的图像序列：分镜、漫画、IP 套装、表情包等。
- 触发方式：用"**一系列 / 一套 / 组图**"这类词，或**直接给张数**：
  ```text
  参考这个 LOGO，做一套户外运动品牌视觉设计，品牌名称为"GREEN"，包括包装袋、帽子、卡片、手环、纸盒、挂绳等。绿色视觉主色调，简约现代风格。
  生成四张图，影视分镜，分别对应：宇航员在空间站维修飞船、突然遇到陨石带袭击、宇航员紧急躲避、受伤后惊险逃回飞船。
  生成周一到周日共七张手机壁纸图，自然景观，每张图对应标注日期。
  ```

## 8 模型与能力（火山方舟）

| 模型 ID | 能力 | 备注 |
|---|---|---|
| `doubao-seedream-5-0-pro-260628` | 图层拆分、单图生成、文生图、单张图生图、多参考图生图 | 限流约 500 IPM |
| `doubao-seedream-5-0-flash-*` / `5-0-lite` | 单图生成、文生图、图生图、多参考图、组图生成 | lite 同 5.0 语言集 |
| `doubao-seedream-4-5-251128` | 单图生成、文生图、单张/多参考图生图、组图（文生组图 / 单张图生组图 / 多参考图生组图） | 官方标注"即将下线" |
| `doubao-seedream-4-0-250828` | 同上四类任务 | 老版本 |

**限流**：最大 IPM（张/分钟）约 **500**，属非刚性保障（受平台负载与调用方式影响）。

## 9 本项目出稿模板（角色/场景 → Seedream）

```text
<用途/类型一句>：<主体 + 行为 + 环境>；<风格词：媒介 + 色调 + 光影>；<构图：景别 + 视角 + 留白位置>；
<必须保留项（若挂了参考图）：参考图中的人物形象/风格/款式…>；<尺寸与交付要求>。
```

要点复述：
- **一句用途**开头（"做一张角色立绘 / 分镜关键帧 / 信息图"），模型会据此选版式；
- **连贯短句**，不要逗号 tag 堆；
- 有参考图 → 写"参考对象 + 生成画面"两段；
- 要文字 → 直接写文字内容并说明位置（Seedream 中文/多语言文字渲染强）；
- 组图 → 给张数或写"一套/组图"。
