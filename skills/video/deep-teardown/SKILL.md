# Deep Teardown — 深度拉片（复刻级拆解）

> 触发：拉片室「深度拆解（复刻级）」发来、消息带 `【深度拉片请求】`。
> 目标产物 = **详细设计报告（复刻规格版）**：拆到逐镜，按它能把参考片复刻出来。
> 与常规拉片的区别：常规只借手法；深度要拆到**每镜的复刻配方**（时间码/时长/机位/运动/动作/服装道具/光影/声场 + 怎么做出来）。
> 长模型全免费（longcat），**调用量不设限**——但读图张数按本文预算走（一墙一次读完，别来回读）。

## 输入（消息里拿）

- 参考片：uploads 文件名（`path`）或直链（`url`）；片长；可选 `素材区间`（给了就只拆区间内）；可选 `补充侧重`。
- 工具全部走本机 127.0.0.1:5001。**容器里可能没有 curl**（2026-10-17 实测无）：先 `curl --version` 探一下，
  没有就用 python3（urllib/requests）等价调用——下方所有 curl 示例只作接口语义示意，JSON 照抄、调用方式自换。
- 帧图都在 `data/uploads/`，读图用自带读图工具（read_image 认 jpg）。

## S0 · 切点扫描（1 次调用，纯数据）

```bash
curl -s -X POST http://127.0.0.1:5001/api/v1/tools/video-scenes \
  -H 'Content-Type: application/json' \
  -d '{"path":"<参考片>","scene":0.35,"min_shot_s":0.5,"long_shot_s":12,"scene2":0.15}'
```

拿回：`shots[]`（i / start_s / end_s / dur_s，拆出来的带 `sub:true`）+ `cuts[]` + `sub_cuts[]` + `stats`。区间模式补 `"start_s"/"end_s"`。
- **长镜二级扫描（默认开）**：主阈值 0.35 对快切蒙太奇段会整段漏检（实测 80.9s「长镜」内有 18 个真切点）——
  ≥`long_shot_s`(12s) 的镜会自动在镜内用 `scene2`(0.15) 再扫一遍并拆细；要更细可 `long_shot_s=8`，要关传 `0`。
- S1 读帧墙时**顺带复核 sub 镜**：相邻两镜画面完全连续（无跳变）→ 是误拆，报告里并回前一镜并注明。
- 镜头数 **>110** → S1 用 `per_shot=2`；**>140** → 拆两段（先拆前半再拆后半，S4 再合）。
- 切点太碎（均值 <1.5s 且肉眼觉得误切）→ `scene` 提到 0.4 重扫；片子太平没切点 → `scene` 降到 0.25。
- `min_shot_s` 是合并超短镜的阈值：要原样切点传 `0`。

## S1 · 全片帧墙 + 逐镜镜头卡（1 次调用 + 读图）

```bash
curl -s -X POST http://127.0.0.1:5001/api/v1/tools/shots-frames \
  -H 'Content-Type: application/json' \
  -d '{"path":"<参考片>","scene":0.35,"min_shot_s":0.5,"per_shot":3,"tile_w":320,"cols":8,"rows":3}'
```

拿回：`sheets[]`（每张 8×3=24 格，格上烙着 `#镜号 绝对秒` 标签）+ `frames[]`（每镜 per_shot 张带标签缩略图：`{shot, time_s, name}`）。
`keep` 默认开 → 帧文件保留（`data/uploads/st_*.jpg`），**S4 报告配图直接用这些 name**。
一墙覆盖 8 镜；64 镜 ≈ 8 墙。**逐墙读完**（`data/uploads/sh_*.jpg`），边读边落「逐镜镜头卡」：

| 字段 | 写法 |
|---|---|
| 镜号 / 时间码 / 时长 | 照 S0 的 shots（绝对秒） |
| 景别 | extreme_close / closeup / close / medium_close / medium / medium_full / full / wide |
| 机位视角 | 正面 / 背面 / 侧面 / 过肩 / 俯视 / 仰视 / 主观 |
| 运动 | 固定 / 推 / 拉 / 摇 / 移 / 跟 / 环绕 / 升降 / 手持；三帧差分推断不出就写「未定（静帧）」 |
| 主体与动作 | 谁 + 在做什么 + 推进方向，一句话 |
| 服装 / 道具 | L0 完整 → L4 全裸（衣物状态）+ 道具/被单状态 |
| 备注 | 光位/色温、字卡、水印、看不清要精拆的点 |

帧墙 320px 看不清的细节标「待精拆」，留给 S2。

## S2 · 关键镜精拆（1-2 次调用 + 读图）

挑关键镜 **≤14 个**：开场钩子（前 2 镜）、动作/强度峰值、情绪高点（泪/汗/失神）、转场与体位切换、结尾收束、以及 S1 标「待精拆」的。
把它们的 `[start_s, end_s]` 列表喂回同一端点、换大格：

```bash
curl -s -X POST http://127.0.0.1:5001/api/v1/tools/shots-frames \
  -H 'Content-Type: application/json' \
  -d '{"path":"<参考片>","shots":[{"start_s":0,"end_s":80.9}],"per_shot":4,"tile_w":600,"cols":6,"rows":4}'
```

（14 镜 × 4 帧 = 56 格 → 6×4 两墙半；读完补全：动作推进细节 / 运镜四帧差分 / 接触点 / 光影色温。S2 的 `frames[]` 同样可用于报告里关键镜的加图。）
实在要单帧全尺寸：`{"path":..., "start_s":x, "end_s":y, "max_frames":4}` 走 `/v1/tools/video-frames`。

## S3 · 节奏结构（不用图，用 S0 数据算）

- 镜头时长分布（均值/中位/极值）+ 切点密度分段（把全片切 ≤6 段，每段一句话）；
- **爆点表**：显性动作/情绪高点逐条列（绝对时间码 + 强度 1-3 + 这镜在卖什么）；
- 开场 3 秒钩子拆解（第一镜第一拍给了什么：视线/体液/道具/表情）；
- 全片强度曲线一句话（蓄-放节奏、几段峰值、收束方式）。

## S4 · 详细设计报告（最终回答全文，只出报告）

按这个骨架出（**每镜一块**，64 镜就是 64 块；不缩水、不合并、不「同理」）：

1. **全片速览**：一句话定位 + 段落表（段 / 时间码 / 镜数 / 内容一句话）+ 节奏曲线一句。
2. **逐镜复刻表**（每镜）：

```md
### 镜 12 · 01:23.4–01:29.2（5.8s）

![镜 12 · 01:23.4](/api/images/<该镜中间帧 name>)

- 景别/机位/运动：medium_close · 正面微俯 · 手持轻推
- 画面：她跪坐床沿、他站身后双手按肩；窗光右侧入画（≤40 字）
- 复刻要点：① 构图：……；② 运动：……；③ 时长与峰值：峰在 4.2s（每条 ≤30 字，写「怎么做出来」）
- 首帧图要点：一句话（角色/姿势/服装 L 档/构图/光位）
- 视频 beat：0-Xs 干什么 → X-Ys 干什么
- 声场：呼吸/床架/无台词 or 台词原文 · 档位：sfw/nsfw · 强度：1-3
```

3. **连续性账本**：服装 L 档、道具、体位、场景的跨镜变化点逐条列（复刻时防穿帮）。
4. **复刻施工建议**：哪些镜锁首帧（I2V）、哪些纯文生（T2V）、多参考图怎么配；难镜清单（复杂肢体/液体/快速运动）+ 降级策略；总时长对齐表（段-镜-秒）。
5. 若消息有 `补充侧重`，单起一节回答。

## 预算与纪律

- 读图：S1 全墙读（64 镜 ≈ 8 墙）+ S2 ≤3 墙；不上单帧碎读除非必要；一墙一次读完。
- 单次 `shots-frames` 上限 336 帧（超了降 `per_shot` 或拆段）；镜头上限 140。
- **只出报告：不落盘、不出分镜、不改任何库**；报告即最终回答全文。
- 时间一律**绝对时间码**（如 `01:23.4`），别用「第 3 帧」这种相对说法。
- 复刻要点写「怎么复现」，不写「为什么好看」；不复述画面本身当要点。
- **NSFW 用语一律直白**（2026-10-17）：器官/行为/体液直接用
  `../skills/video/nsfw-directing/references/acts-lexicon.md` §9 直白词表（`阴部/阴茎/插入/抽送/精液/cowgirl`…）。
  报告要能**直接转提示词**——写「结合部/亲密/白浊」这类回避语＝丢信息，下游画不出来；
  explicit 档的镜头卡禁止写成含蓄描述（含蓄只在引擎带审核时的降级表里）。
- **每镜必须配 1 张帧图**（`![镜 N · 时间码](/api/images/<name>)`，name 从 S1 `frames[]` 里该镜的**中间帧**逐字复制，别手敲）——
  报告在拉片室是带图渲染的；S2 精拆过的关键镜可再补 1 张（首/末帧）。S1 若传了 `keep:false` 则无图可配。
- **角色命名纪律**：**不猜 IP 角色名**。名字只在标题/字卡/画面文字有证据、且与外观对得上时才用
  （本片标题只给了 `Roxy` → 蓝发女主可用；棕发男主无证据 → 称「棕发男主」）；同一角色全片同一个称呼，
  报告开头「角色」行写清依据。宁可用外观描述，**不许张冠李戴**（把男主叫成原作别的角色=整份复刻规格污染）。
- 最终回答**从报告标题开始**（顶多一行开场），不带「现在出报告」这类过程性前言；结尾照旧标「只出报告」。
