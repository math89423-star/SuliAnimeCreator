# 投流批量（方案包 canonical，不碰成片）

> 归属（2026-10-14 新建）：投流批量归本文件；剧本写作归 `short-drama-write`，资产归 `short-drama-assets`，分镜归 `short-drama-storyboard`，审查归 `short-drama-review`，通用发散归 `creative-divergence`。本文件只做 `任务 → 方案包`，不写剧本正文、不拆资产、不审艺术、不生成媒体。

把一句投流任务变成 N 条可测试、可执行、可复盘的方案包，交给 L-Port 实施。

## Quick Start

输入一句任务，输出一个方案包。任务四件套缺一不可，缺的先按默认值补并明示：

```text
任务：做15条投流，引导点击红包广告的，用已有的素材库剪辑，不额外生成新视频
解析：{ n: 15, goal: 红包点击, source: library_only, category: 红包点击 }
输出：PKG-TRAFFIC-<母本>-<日期>.json（高光/文案/素材/拼接四段齐）
```

## 入口（四字段）

1. **任务描述**：自由文本，不会写可传参考视频代替（见 §5）。
2. **投流方式**二选一：`gen`（允许现写新高光）/ `lib`（只用素材库已切好片段，不额外生成）。
3. **投流分类**：即引流目标，`红包点击 / 付费解锁 / 拉新关注 / 直播引流`，决定 CTA 与标题走向。
4. **投流数目**：`15 / 30 / 60`，默认 15；单批上限 120，超了分批。

解析规则：数字+条=数目；`库/已有/不生成/不额外`=lib，反之 gen_ok；`红包/点击/转化/拉新/付费`首命中=目标；`EP-xxx`=母本正片集号，无则用当前集。

## 工作流（任务 → 方案包）

1. **定变量表**：开头钩子 × 人物视角 × 爽点 × 口吻 × 结尾，一次只变 1–2 个。钩子池：冲突直给 / 悬念提问 / 反差 / 台词爆点 / 动作奇观；爽点池：打脸 / 逆袭 / 误会揭晓 / 高能反转；口吻：冷静 / 悬疑 / 强情绪。
2. **配高光（双来源）**：`generate`=现写高光描述；`library`=引用已切好片段 ID/时间段，只存引用不存文件。lib 模式轮询素材库，gen 模式每 4 条插 1 条现写。
3. **写文案草案**：Hook（一句话+首镜+首句台词）/ Body（中段因果）/ CTA（点红包→看正片类）/ 标题。每版一句**测试假设**（如 `A1测冲突前置能否3秒留人`），说不清差异不开工。
4. **排拼接计划**：`Hook(4s) + Body复用 + CTA(3s)`，单条 15–30s；只写顺序+时长+文案段，不写剪辑参数。
5. **命名导出**：`{package}_{variant}_{highlight}_1080x1920.mp4`，跑量档另出 720x1280；包内四段 `highlights / copy_draft / materials / splice_plan` 齐才算完。

## 剪辑逻辑（agent 必须懂）

- 前 3 秒定生死：85% 划走在前 3 秒，钩子公式=`用户 + 痛点/利益 + 悬念/反常识`，0.8 秒内让人觉得走了会亏。
- 有效多版本四层必须实质不同：开头 3–5 秒讲什么 / 谁在讲 / 中段选哪段因果 / 结尾停哪。只换标题、字幕色、配音音色不算新版本。
- 画面服务文案：文案定画面顺序，不是原片缩短；中段因果重排时镜头跟着重组。
- 参考视频输入：用户传片代替描述时，先按片内高光出变体，占位描述=`参考视频已传，按片内高光出变体`，全自动解析（抽帧+视觉描述）是后一步增强，当前先引用跑通。

## 质量门（四项全过才导出）

1. **可测性**：每版有独立测试假设，可归因到钩子/视角/爽点之一。
2. **差异性**：任意两版至少差一层（开头/视角/爽点/结尾），去重靠 `hook+视角+爽点+结尾` 联合 key。
3. **可执行性**：L-Port 打开包能直接剪：高光引用可定位、文案段与拼接 order 一一对应、时长加总 15–30s。
4. **可复盘**：文件名即测试方向，包内 `task/假设/命名规则` 齐，回传 CTR/3s完播/转化后能反查是哪层赢的。

## 反模式（别做）

- 把大纲/分镜 duty 当投流母本：投流母本是正片成片池+高光池，不是策划文本。
- 一次全轴全变：开头画面口吻节奏全换，数据好了也不知道谁的功劳。
- 为凑数出的换皮版本：标题不同但前 3 秒镜头 identical，直接废掉。
- 在 Suli 侧生成成片：本项目只出方案包，成片、key、队列、媒体库全在 L-Port（POSITIONING §4 红线）。
- 批量包里塞二进制：只存引用 ID/文件名，文件靠人工搬运，sha 对不上停手上报。

## 安装维护

纯文档 skill，无脚本。改词表（钩子/爽点/口吻）直接改 §工作流第 1 步，保持与前端 `/traffic` 任务四字段同名（desc/mode/category/count）。
