# Costume Design（S1-3b 服装细化唯一入口）

> 归属：身份层归 `character-design`（三锚/三色/选型单 canonical，不在此重定）；画前几何纹样检查归 `aesthetic-fashion-design`；代码落盘归 `garment-flat`。本文件只做**个性层服装细化**：通用层复用 + 个性层出 push 版 + 分层定级 + 换装素体。

## 契合第一（最高指令，压过一切）

- 服装除非额外说明，必须契合角色的体型、外貌、发色、气质，一并考虑：高挑苗条不堆大裙摆（压个子），黑发冷脸不大面积暖色（抢气质），长发不做颈部繁复（和头发打架）。
- 切忌为了华丽而华丽：每加一件都要回答"这件让角色更像她自己了吗"，答不上来就砍。
- 优先级铁序：**角色契合 > 主题契合 > 大胆度 > 完成度**。下级原则与上级冲突时听上级的。

## 核心理论（引用 canonical，不重定）

- 三级 anchor / 三色层级 / Signature 唯一 / 选型单格式：见 `character-design`（身份评审清单+选型单），此处不复述，直接引用。服装层只补充：个性层 signature 必须落在服装件上，通用层沿用不重复立锚。
- 本文件专精：部位×元素矩阵、流派元素包、现实→二次元转译、双层设计法、分层定级、大胆度基线、换装素体。

## 部位×元素矩阵（中文 → prompt 英文）

- 颈部：项圈 `choker` / 十字架项链 `cross necklace` / 丝带领结 `ribbon tie` / 蝴蝶结领结 `bowtie` / 领巾 `neckerchief`
- 胸部：大蝴蝶结 `large bow` / 胸针 `brooch` / 徽章 `emblem` / 吊带 `suspender straps` / 背带 `suspenders`
- 腰部：腰封 `corset belt` / 背带腰封 `harness belt` / 腰链 `belt chain` / 裙链 `skirt chain` / 蝴蝶结腰带 `bow belt`
- 腿部：腿环 `thigh strap` / 袜带 `garter` / 吊袜带 `garter belt` / 网袜 `fishnet stockings` / 条纹袜 `striped socks` / 膝上袜 `over-kneehighs`
- 发部：发夹 `hairclip` / 丝带发饰 `hair ribbon` / 蕾丝发带 `lace headband` / 发链 `hair chain`
- 手部：戒指 `ring` / 手链 `bracelet` / 臂环 `armlet` / 美甲 `nail polish`（如 `dark red nail polish`）/ 手套 `gloves` / 袖套 `detached sleeves`
- 鞋部：厚底 `platform shoes` / 玛丽珍 `mary janes` / 绑带罗马 `strappy sandals` / 鞋链 `shoe chain` / 鞋饰蝴蝶结 `shoe bow`
- 万能材质词：蕾丝 `lace` / 荷叶边 `frills` / 链条 `chains` / 绑带 `straps` / 金属扣 `buckles` / 铆钉 `studs` / 珍珠 `pearls` / 丝绒 `velvet` / 缎面 `satin`

## 流派元素包（发散时三选一或混搭，但 signature 只留一个）

- 暗黑地雷：十字架/腿环/厚底鞋/暗红甲/颈链，主黑白 + 暗红点缀，适配冷淡厌世。
- 量产甜心：大蝴蝶结/蕾丝/珍珠/爱心，主白粉。
- 哥特萝莉：拉夫领/束腰/繁复褶皱，主黑 + 白。
- 机能叠加：harness/绑带/金属扣/多口袋，主黑灰，荧光点缀慎用（二次元里易脏）。
- 学院精致：领结/裙链/蕾丝边/暗色发夹，守学院感做精致化。

## 现实→二次元转译（本次"太素"的根因修复）

- 现实词（毛混纺/贝壳扣/明线）只进结构位（S1-3a），味道一位不给。
- 味道靠形状词 + 点缀色（S1-3b）：不对称、撞色、混材质是三次元转二次元最便宜的三招。
- 警告：细链条/小字/多小物难生成，复杂系带降级为粗带；文字图案一律不写。

## MCP 路由（本项目已接线）

- 中文元素词先调 `booru-pictag-get.autocomplete_tags` 转标准 tag，不确定拼写先查后写；`costume.html` 已内置 18 风格包 + 198 件单品的校对 tag 与搭配台，选型/定样优先查它，查不到再走 MCP。
- 要同类画法例文：`civitai.search_images`（withMeta=true 拿 prompt/negative/steps）。
- 点缀色：查 `palette.html`；某词生图偏色后回改词条（见 AGENTS.md §9）。
- 一次 S1-3b 只查 1-3 次，结果沉淀为 prompt 里的 tag，不要预拉全量。

## 主题契合与对标（只做服装层对标，身份对标归 character-design）

- **主题第一门**：服饰设计首先契合角色身份主题。在校 JK 只用校园语境单品（领结/领带/发带/发箍/校徽/袖章/腕表/袜款/鞋款/开衫背心）；流派元素包必须先过主题筛——地雷三件套（十字架/腿环/厚底）、网袜、机能 harness 与学生身份冲突的一律排除，再谈大胆。大胆只在主题内大胆。
- **服装层对标**：只对标服装（版型/叠穿/材质/配色逻辑），不重做身份对标（脸/发型/气质归 `character-design` §对标检索）。借元素不借脸和发型，注明来源。

## 双层设计法（通用穿搭 vs 个性穿搭，分开独立设计）

- **通用层**：乐福鞋/丝袜/百褶裙/白衬衫基础款这类高度通用、一旦定型极少改的单品。求稳不求新，锁定后沉淀为可复用资产（本项目黑乐福鞋+黑薄丝袜+黑刀褶裙即第一套通用层）。
- **个性层**：上装 + signature 配饰。角色有没有特色只看这一层，设计火力 80% 投这里：领型/开合/叠穿/不对称/材质撞色/点缀位置，至少给出一处"只属于这个角色"的形状记忆点。
- 两层独立出方案、独立冻结：通用层沿用旧规格不再重画；个性层每版必有形状变化，沿用=废案。
- 评审时分开看：通用层只查一致性（和库存规格一字不差），个性层才查大胆度与 signature 唯一性。

## 本地实测沉淀（Illustrious 线，彩境天工 v7，1536×1024 / 1024×1536）

- JK Uniform Variety 即使 0.3 仍会加戏（红发绳、背后大蝴蝶结、裙装变体）：服装基座已在 Master 冻结时，配饰拆分图可裸跑底模 + 细节 LoRA，不挂制服 LoRA。
- **校徽/纹章倾向是底模自带的**（挂不挂 JK LoRA 都会出）：胸前必须写 `plain blazer front` + negative 常驻 `emblem, crest, badge`，仍漏网就 Inpaint 点掉（面积小，好修）。
- **red 会往眼睛爬是底模行为**：凡有红色配饰，眼色必须在 prompt 里写死（`black eyes`），即使 neck-down 构图也要写（取景会漂移）；negative 常驻 `red eyes`。
- "reference sheet" 易召出训练集 artifact（十字标记、多人物增殖、黑条遮脸）：要么改写成 four-panel layout，要么退回单张分开出（成功率高得多）。
- 上装定样用 neck-down 构图隔离脸部变量（已验证有效），脸等 S1-4 再验；但眼色词仍要写，防取景漂移。
- 领结结型本身模型画得很好，问题永远出在"多出来的东西"，评审时先数件数再看结。

## 选型→定样（只做服装层定样，身份选型归 character-design）

- 身份选型（脸/发/体型/锚点）见 `character-design` 选型单，不在此重选。
- **服装定样**：对已拍板的服装选型单逐项定颜色（查 palette）/材质/装饰母题/固定点/穿着层级，转英文 tag（booru 转译），拼成完整方案。

## 设计与验证顺序

- 设计由外到内：外套定剪影 → 才知道内搭露多少 → 配饰填开口（红领结填领口 V 区即实例）。
- 验证由内到外：身体 → 内搭 → 外搭 → 配饰固定层（穿着层级，taxonomy §43.6 同款）。

## 换装素体（定妆照规则）

- 后续任何新服装定妆/二创换装，先出素体照再换装：角色仅穿内衣和内裤（简单款、无花纹），其余裸露，中正站姿，正面。
- 目的：底图不带旧服装，避免 img2img / Inpaint / 垫图换装时旧衣服残留干扰。
- 素体 prompt 要点：脸/发型身份锚定不变 + `wearing only a plain bra and panties` + 中性纯色背景；S1-1 已有衣服的 Master 本体不受影响，素体是换装专用前置件，不进人物包 Master。
- **已验证（fx 云端 A/B，结论固化）**：垫穿旧衣全身图合成新衣，旧衣残留干扰明显；改垫半身（服装信号少）效果明显更好。母图服装越少干扰越小，素体最优——初始母图保持最大程度裸露（仅内衣裤）是必要项，不是可选项。

## 素体三母版（标准三件套，着装版同构复用）

- **M1 近身大头照**：肩往上，正式正面镜头。验脸/发/瞳，兼做脸部基准升级件。
- **M2 上半身照**：腰往上，2/3 侧视（身体微侧、脸转镜头）。验颈肩线条与上半身比例。
- **M3 全身照**：一幅图内正面＋背面两全身并立（无分隔线，防 grid artifact），中正站姿。验全身比例与背部结构。
- 三张统一：同一身份锚定、同一纯色背景、同一平光、中性非暗示性姿态；negative 常驻 `nsfw, nude, suggestive` 保临床感。
- 新角色开第二套前三张先齐；着装版 Master（S1-1/S1-2/转面）与素体版一一对应。

## 分层拆解（按服饰复杂度定级，绝不写死格数）

开工先定级，定级依据 = 层数 × 部件数 × 原创度；加饰后层数增加可上调等级。

- **L1 极简**（泳装/睡衣/体操服/连体衣）：1-2 格。拆剪裁线 + 露肤度 + 材质光泽（包边/系带/纹路），不拆部件。
- **L2 简单**（T恤短裤/基础水手服/单件连衣裙）：2-3 格。上装 / 下装 / 局部纹样或鞋。
- **L3 中等**（外套+内搭/制服三件套/多层日常）：3-4 格。外套 / 内搭 / 下装 / 鞋袜，可四宫格单张一次出。本次黑 JK 即此层。
- **L4 复杂**（洛丽塔/哥特/军装/和洋折衷多层）：4-6 格，允许两轮。第一轮分层总览（外层/中层/内搭/下装同框），第二轮单层特写 + 头饰 + 袜鞋。
- **L5 自创/概念**（原创种族/幻想装甲/异世界服）：不限格数。先出设计三视图（正/侧/背）+ 材质色板 + 部件编号图，用户逐轮拍板后再逐部件细化。

## 大胆度与主动性基线（本 skill 最高指令）

- 二次元服饰默认比现实**华丽、大胆、开放一档**：露肤度、不对称、混材质、装饰密度上限全部高于现实。现实考据只管结构合理，不管保守；保守是 bug。
- 每次 S1-3b 至少出一版 **push 版**（比用户描述再大胆一档），和守成版并列供选择。
- 主动设计，不要等投喂：按部位矩阵 + 流派包出完整方案，用户只做选择题；用户只说"看着办"时默认 push 版方向。
- 大胆不等于堆料，仍受质量门约束（件数≤2、signature 唯一、剪影检查）。开放剪裁优先动**肩/腰/腿**三处，脸和发型绝不动。
