# Character Design（STEP 1 角色设定，LLM 主战场）

## 定位与分工（先读）

- 本 skill 管**身份层设计**：一句话母题 → 性格视觉化 → 脸/发/体型 → 脸标 → 三锚 → 形状母题 → 配色三层 → 服装语言初定 → 写 `character.md`（唯一真源）。
- 交棒：服装加饰细化定样（S1-3b）→ `costume-design`；画前方向锁定+品类几何 → `aesthetic-fashion-design`；代码化flat落盘 → `garment-flat`；出图 prompt 组织 → `illustration-prompt`；机位构图 → `composition-camera`。
- **Identity 可冻结，State 必须放开**：本 skill 只锁身份，不锁动作/表情/镜头（归 STEP 2）。
- 终点：选型单经用户拍板 → 按本文规格写入 `character.md` → 进 S1-1~S1-7 图像管线。
- **canonical 声明**：三锚/三色/选型单/对标规则以本文件为准；`costume-design` 不重定三锚三色，只做服装层细化；`aesthetic-fashion-design` 不重定配色，只做画前几何纹样工艺检查；`garment-flat` 不谈审美，只做代码落盘+门禁。

## 六步流程

1. **母题提取**：把用户 idea 压成一句话母题 = 气质 + 身份/标志物（+ 场景感），如"冷漠疏离的黑长直 JK 少女"。母题是全案总约束，后续每个选型都要能回答"它让角色更接近母题吗"。
2. **发散 3 方向**：给 3 个立意见明显不同的人设方向（不是换词）：每方向 = 母题句变体 + 性格核心 + 视觉钩子；默认取 3 个不同气质做对照。
3. **逐层落位**：性格→视觉（查转译表）→ 脸/眼/发 → 体型剪影 → 脸标（四选一）→ 三锚（大/中/小）→ 形状母题（查库）→ 配色三层（查 `palette.html`）。设计由外到内：外轮廓先立，再定内层露多少。
4. **taxonomy 选型**：body 树与 fashion 树按部位选到叶节点，**记录完整路径**（如 `上装-外搭-西装-学院西装`）；通用层求稳、个性层求新；汇总成选型单。
5. **验证**：逐项过 §身份评审清单。
6. **收敛落盘**：选型单给用户拍板 → 写 `character.md`（母题总览 + 章节结构 + 取值状态）。

## 性格→视觉转译表（全谱系，定情绪基调后查）

通用原则（各条独立成立）：
- 眼是第一生产力：大=开放，小=疏远；曲=温，直=冷；外眼角下垂=内向忧郁；高光少=疏远。
- 眉毛占一半表情语义：刘海遮眉=语义浪费（若故意遮，把"无眉可见"当设计语言写进母题）。
- 体型语义：曲线（圆）=亲和；削弱曲线/直线剪影=疏离。
- 遮=内向：遮眉/遮颊/遮背/厚重分层是同一套身体语言。
- 反差=记忆点：气质 × 一件违和元素（冷淡 × 软玩偶挂件）。

| 气质 | 眼 | 发 | 剪影/体型 | 配色倾向 | 标志物倾向 | 备注 |
|---|---|---|---|---|---|---|
| 冷淡疏离 | 细长/中小/平直微垂/高光少 | 长直/齐刘海/发尾平齐 | 直线/削肩窄胯/高挑 | 黑蓝灰白冷色域+小点缀 | 单枚几何金属件 | 留白即语言，宁少勿多 |
| 元気明朗 | 圆大/眼角上挑/大高光 | 蓬松/短中/外翘 | 重心偏上/开阔 | 橙黄珊瑚白+撞色 | 发圈/运动元素 | 可多元素但乱中有序 |
| 内敛文静 | 中等/下垂眼角/柔高光/长睫 | 柔顺长发/侧分/内扣 | 收敛/含胸体态 | 米灰蓝棕低饱和+淡彩 | 书/眼镜/低调发夹 | 内向=隐藏逻辑（遮眉/厚重分层） |
| 傲娇 | 上挑眼角/锐利/高光偏上 | 双马尾/卷发/动感 | 直/微昂下巴 | 红粉+黑白基底 | 缎带/成对蝴蝶结 | 核心是反差：姿态凶元素甜 |
| 神秘 | 半遮/瞳深/高光极少 | 遮眼刘海/暗色长直或波浪 | 垂坠包裹感 | 黑紫深绿+金属 | 斗篷/兜帽/古物 | 遮是手段，露出的部分要精 |
| 温婉柔和 | 杏眼/无锐角/柔和高光 | 波浪中长/编发/侧披 | 曲线/柔肩 | 粉米奶白+珍珠 | 蕾丝/缎带/花饰 | 全线去锐角 |
| 飒爽英气 | 锐利/平直/视线正 | 高马尾/短发/利落 | 挺拔/肩线展开 | 黑白军绿+金 | 皮带/金属扣/剑柄形 | 线条少而准，一根是一根 |
| 病娇 | 瞳孔骤缩感/高光异位 | 凌乱/遮半边/不对称 | 静态紧张 | 黑白+血红点缀 | 绷带/利器轮廓/单侧 | 不对称是主语言；慎用 |
| 腹黑 | 眯眼笑眼/瞳半遮 | 整洁/暗色/一侧垂发 | 端正带锋利转折 | 深色+紫金点缀 | 折扇/眼镜/手套 | 笑与冷的落差=眼型×嘴型 |
| 天然呆 | 大而散焦/高光散/圆瞳 | 蓬松乱/呆毛/发尾翘 | 松弛体态 | 粉彩亮色 | 戴错位的小物 | 呆毛非唯一解 |

## 形状母题库（选定后发/领/褶/饰/纹样全线复用）

| 母题 | 气质语义 | 贯穿位置 |
|---|---|---|
| 垂直 | 冷淡/凛冽/秩序 | 直发轮廓/平驳领/刀褶/长条饰件 |
| 水平 | 安定/沉稳 | 一字领/宽腰带/裙腰线 |
| 圆 | 亲和/软萌 | 圆弧领/荷叶边/圆饰件/蓬袖 |
| 锐角 | 攻击/英气 | V领/尖角领/燕尾/箭头饰 |
| 波浪 | 浪漫/流动 | 波浪发/波浪褶/飘带/水纹 |
| 对称 | 端庄/仪式感 | 中分/双排扣/对称发饰 |
| 切线/不对称 | 个性/叛逆 | 单侧发饰/不对称裙摆/斜裁/单边袜 |

规则：母题一确定，违背母题的选型一票否决；跨图识别靠同一母题反复出现。

## 发散菜单（第 2 步取用）

1. **属性组合**：职业/社团 × 时代（古典/现代/近未来/幻想）× 气质 × 标志物（乐器/武器/书/相机/器皿…）。
2. **反差设计**：气质 × 一件违和元素（冷淡 × 毛绒挂件；英气 × 蕾丝）。
3. **主题隐喻**：把 idea 的情绪翻译成可穿戴符号（孤独 → 单侧耳饰/缺一半的对称）。
4. **二创融合**：借 1 件元素，不借脸/发型（撞车即废）。
5. **母题变体**：同角色不同时空/场合版本（校服版/私服版/礼服版）。

## 对标检索（出方案前，1-3 次为限）

1. 对标优先级：同气质 > 同身份 > 同配色；三中全中只借 1 件，避免仿作。
2. `booru-pictag-get.danbooru_get_character_profile` 查高人气同类角色 → 列"借/不借"清单。
3. `civitai.search_images`（withMeta=true）找同类画法例文。
4. 注明对标来源；token 节制，结果沉淀为 tag/结论，不预拉全量。

## 改动量级（动手前先声明，量级外不讨论）

- A 微创：配饰/脸标/眼强化，不动已冻 Master 图。
- B 中改：发型剪影手术，S1-1 重出、S1-2/S1-4 连带重冻。
- C 重做：发型级，全线重冻。

## 输出模板

Identity Block（英文，供 prompt 引用）：

```text
1girl, solo, [age feel], [hair color] [length] [style] hair, [bangs], [eye shape] [eye color] eyes, [pupil/highlight], [face shape], [face mark], [height/build silhouette], [frozen outfit items], [accessory], [main colors]
```

Identity Block（中文直译，与英文同序）：`1girl, solo, 年龄感, 发色长度发型, 刘海, 眼型眼色, 瞳孔/高光, 脸型, 脸标, 身高体型剪影, 已冻服装清单, 配饰, 主色`。

使用提示：配 §8 一致性锚定句；服装细节按"文字指位"原则不展开（见 AGENTS §8 着装提示词技巧）；脸标/痣/发用文字补强。

选型单：

```markdown
| 部位 | taxonomy 路径 | 候选 | 定样 | 状态 |
|---|---|---|---|---|
| 上装-外搭 | 上装/外搭/西装/学院西装 | 双排扣短款 / 单排 | 双排四扣短款 | ⏳ |
```

`character.md` 页面规格：
- 头部：母题总览（一句话母题/情绪基调/主色/视觉重点）。
- 第一章 body：叶节点路径 + 取值（对应 `anime_body_design_taxonomy.md`）。
- 第二章 clothes：叶节点路径 + 取值（对应 `anime_fashion_accessory_taxonomy.md`）。
- 取值状态：✅已冻结 / ⏳待定版 / ⬜未设定；无明确写入的一律按"无"处理，不脑补。

## 身份评审清单（进 S1-4 前逐项过）

- [ ] 剪影三距：远（大锚可读）/ 中（中锚可读）/ 近（小锚+脸标）；不对称优先；多角色并排不混淆。
- [ ] 三锚各立其一：大（发/头剪影）/ 中（服装形/主色块）/ 小（配饰/脸标）。
- [ ] 脸标唯一：痣/疤/纹/异瞳四选一，最多其一。
- [ ] 点缀色落位：查 `palette.html`，主/辅/点缀三层各就各位。
- [ ] 复杂度 70/30：大面积留白，视觉焦点 ≤3。
- [ ] 可生成性预警：细链条/小字/多小物 → 降级为粗带/无字/少件。
- [ ] 体型 signature 保形：转面/动作只许强化不许改型。
- [ ] 改动量级已声明（A/B/C）。
