# Flat 制图约定（本 skill 制图铁律，draw 之前必读）

> 取自工业 flat 规范（实线＝缝/边、虚线＝明线、点线＝暗线/折叠）＋本项目二次元适配
> （允许主题色与红衬示意，不做黑白印刷限制）。

## 1. 视图

- 必备：服装类正/背视图齐全，复杂款加侧面 SIDE 剪影；品类视图按 components.md 执行
  （鞋：侧视为主＋正视鞋头＋后视后套；袜/衬裤：正视＋背视；配饰：正视为主，手套加背视）。
- 不对称部件（偏襟、单侧徽章、单侧开衩）**单画并在标题声明**，禁止用“对称制图”一笔带过。
- 仅保正交视图；任意透视不承诺（需 L2 代理体，另案）。
- 人物方位永远双基准：“穿着者左胸＝看图右侧”。
- 成双物品（袜/手套）：单只画法＋标题“×2”注，左右一致性进垫图检查。

## 2. 线型语义（全款统一，违者返工）

| 线型 | 语义 | SVG |
|---|---|---|
| 粗实线 2.0–2.2px | 服装外轮廓 | `S(2.2)` |
| 细实线 1.0–1.6px | 内部分割/省/褶脊/贴边边界/拉链牙线 | `S(1.0–1.6)` |
| 虚线 | 明线（topstitch）、褶谷线、隐形结构 | `stitch()` |
| 点划线 | 对称中心线 | 手写 dash `14 5 3 5` |
| 红区/红虚框 | 红衬示意 / 后叠加禁扩散重绘区 | BLOOD 系 |

箱褶等**明褶**用实线画转折面＋褶量箭头，禁止只用虚线表示。

## 3. 标注

- 引线编号（红圈白字）＋底部工艺表，编号与表一一对应，无孤儿编号、无 pro 漏编（口袋/滚边必须进编号）。
- 局部详图 D1..Dn：褶/拉链/蕾丝/徽章/封口，每图有标题＋尺寸＋工艺三行。
- 标题栏：款号＋版本＋日期＋面料＋颜色＋单位mm；图例行常驻。
- 术语白名单：叠门、吃势量、抽碎褶装袖克夫、套结、结构分割缝、风纪钩、睫毛蕾丝、隐形拉链。
  黑名单：前错、后叠加、蓬度、碎褶收袖头、m 代替 mm。

## 4. 层次渲染（解“太平”，只加面不动线）

- 褶：谷线倒向侧深影（黑 0.08）＋脊线对侧淡光（#D8DAE2），倒向箭头标方向。
- 叠压：上层部件投影打在下层上（上层→下层），投影裁于下层区内。
- 面料：斜纹细线 opacity 0.05 裁于衣身内；红衬摆用纵向渐变。
- 蕾丝：牙边＋网眼点；附件：结褶皱线、徽章双圈、包边线。
- 约束：只加 `fill/opacity/渐变`，**不加字**（文本检查不受影响）。

## 5. 文本防叠（机制，自动执行）

- 全部 `T()`/引线编号/工艺表编号登记 bbox（CJK 1.0×字号、ASCII 0.55×字号＋5%余量，偏保守）。
- `__main__` 先查后写：叠压或出界 → 退出(1)拒绝落盘并打印双方 tag。
- 全部文本带白色 knock-out 光环：**压线允许，压字不允许**。
- 白底描边禁止 `fill="#fff" {S()}` 混写（S 自带 `fill="none"` 会导致 SVG 非法，
  已连踩两次）：白底形状一律写显式描边属性。
- 组标签 `<g>` 有开必有合（配饰 glove 缺闭合标签导致整图非法，前车之鉴）。
- 工艺表列数按最长行宽＋余量验算确定，禁止固定列数不验算（列数是算出来的，不是默认值）。

## 6. POM 尺寸表（三列，缺一不可）

- 表式：`| # | 测量点＋测量方法 | 基码值mm | 公差±mm |`，随 README 落盘（与设计要点同节）。
  测量方法必须写到“从哪量到哪”（如袖窿下量边到边），禁写“按图”“照常”等代数词。
- 行覆盖：廓形三围＋本款全部关键结构位（腰头/拉链止点/褶/开衩/徽章位/扣位……），
  无空公差——空公差＝工厂按自家标准做，必须填。
- 缺省公差带（无把握时直接采用，不另找理由）：围长类±10mm／衣长裙长类±10mm／
  小部件（扣/袢/徽章）±3mm／定位（徽章位/开衩顶）±5mm。
- 单码声明：角色设定无放码，基码＝当前角色体型（号型段按 SKILL §7 二次元裁剪 waive）。
- 唯一数据源：POM 只转录 `params.json` 已有数字，不新造数；凡 POM 出现而 params 没有的数，
  先回填 params 再转录，违者返工。

## 7. 比例与详图注记（GB/T 29863-2023 §4.2 取意）

- 同一 `flat.svg` 内正/背/侧各视图必须同比例绘制；标题栏新增“比例”字段
  （款号＋版本＋日期＋面料＋颜色＋单位mm＋比例，主视图一般 1:1）。
- D1..Dn 每个详图必须注明自身比例（如 2:1），与主视图比例关系可推，不许无标放大的“示意放大”。
